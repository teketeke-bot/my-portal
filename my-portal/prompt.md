# プロジェクト概要
外国人美容師向けのポータルサイト。Supabaseクライアント（`lib/supabase.ts`）の準備と新規登録処理が完了しました。

# 今回のタスク: ログイン機能とダッシュボードの動的化
以下の仕様に従って、ログイン処理の実装とダッシュボードのデータ連動を行ってください。

## 1. ログイン処理の実装 (`app/login/page.tsx`)
- フォーム送信時（onSubmit）に `supabase.auth.signInWithPassword()` を実行し、メールアドレスとパスワードでログインできるようにしてください。
- 処理中はボタンを「処理中...」に変更して `disabled` にし、エラー時はエラーメッセージを表示してください。
- ログイン成功後は `useRouter` で `/dashboard` へ画面遷移させてください。

## 2. ダッシュボードの動的化とアクセス制限 (`app/dashboard/page.tsx`)
- ページマウント時に `supabase.auth.getUser()` または `getSession()` を使用して、現在ログインしているユーザー情報を取得してください（ローディング状態の管理も追加）。
- ユーザーが未ログイン（セッションがない）場合は、自動的に `/login` へリダイレクト（`router.push`）してアクセスを制限してください。
- ログインしている場合、ユーザーのメタデータ（`user_metadata.name` または氏名フィールド）を取得し、見出しの「○○さん、ようこそ」を「[取得した名前]さん、ようこそ」と動的に表示するように変更してください。
